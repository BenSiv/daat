# Agent tool: Mermaid diagram creation and rendering -- superseded

**Superseded by [doc/agent-plotting-tool.md](agent-plotting-tool.md).** The original plan here was to vendor `mermaid.js` (~3.5MB, client-side JS) into `vnd/`, served through the existing `/vendor?name=X` route, the same way Toast UI Editor is vendored today. Rejected before implementation: it would have added a real chunk of tracked, dead-until-changed weight to the repo and a whole client-side rendering/timing concern (has the script run yet, for a chat message inserted into the DOM well after page load) that a server-side render sidesteps entirely.

The actual need turned out to be real data plots (line/scatter/bar charts of numbers the agent already has), not conceptual diagrams (flowcharts/ER/sequence). `gnuplot` -- already present in this stack as an unused `gnuplot.lua` wrapper in luam's shared `lib/` -- covers that need as a real deployment dependency (an apt package, same shape as `cmark-gfm`) instead of a vendored library, with no client-side execution surface at all. See the new doc for the resolved design.

**Still genuinely open, not covered by the gnuplot approach**: actual diagrams (flowcharts, ER diagrams, sequence diagrams) that aren't a plot of numbers. If that need comes up for real, the client-side-vendoring analysis in this doc's original version is still the right starting point -- Mermaid's own diagram/layout engine isn't something worth hand-rolling the way this codebase's force-directed graph views were.
